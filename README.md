# Whiteboard Studio — Personal Infinite Canvas

A modern, minimalist personal whiteboard application inspired by Miro, tldraw, Linear, and Notion.

## ✨ Features
- **Multi-Board Management**: Dashboard with templates, star/pinning, search, rename, duplicate, and delete.
- **Infinite Canvas & 16px Dot Grid**:
  - Light mode (`#F1EFE8` bg, `#D3D1C7` dots)
  - Dark mode (`#18181A` bg, `#3A3A3C` dots)
- **Interactive 8-Point Resize Handles**: Drag corners and edges to resize shapes, notes, and images freely.
- **Formatting Inspector**: Font sizes, bold, italic, underline, strikethrough, text alignment, and color palette.
- **Shape Customization**: Fill vs transparent no-fill, rounded vs sharp corners, stroke width options.
- **Sticky Notes**: Square vs rectangle mode with 7 semantic color palettes.
- **Pencil & Eraser**: Stroke weight options (2px, 4px, 8px, 16px) and eraser sizes.
- **Clean Images**: Borderless 3px outline with rounded corners and drag-and-drop/clipboard paste.
- **Notion Context Menu**: Right-click to add links, duplicate, reorder layers, lock, and delete.

## 🚀 Quick Start
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
